# خطة الاستجابة لحادث بيانات

لوليد وفريق PROSM. راجعها مع محاميك: المهل تحددها القوانين المنطبقة وعقودك مع العملاء.

## خلال أول ساعة
1. سجّل الوقت ومن اكتشف الحادث وكيف.
2. أوقف الوصول: دوّر المفاتيح في Supabase، وألغِ الجلسات، وعطّل الحساب المتأثر.
3. احفظ الأدلة: `audit_logs` و`sensitive_access_log` وسجلات Supabase. لا تحذف شيئًا.

## خلال 24 ساعة
4. حدّد المؤسسات والأشخاص المتأثرين، ونوع البيانات، والفترة.
5. أخطر كل مؤسسة متأثرة، فهي المتحكّم، بالقالب أدناه.

## خلال 72 ساعة
6. ساعد المؤسسات في إخطار الجهات المختصة والأشخاص، حسب ما يلزمهم القانون.
7. اكتب تقريرًا بالسبب والإصلاح وما يمنع التكرار.
