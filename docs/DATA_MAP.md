# خريطة تدفق البيانات (أساس سجل المعالجة)

مستند داخلي لوليد، يصلح أساسًا لسجل المعالجة وللتعاقد مع العملاء. ليس استشارة قانونية.

| البيانات | من أين | أين تُخزَّن | من يطّلع | الاحتفاظ |
|---|---|---|---|---|
| الحساب (الاسم، البريد، الدور) | المؤسسة / الموظف | Supabase، الاتحاد الأوروبي (eu-central-1) | المالك، المديرون حسب المواقع، الشخص نفسه | ما دام الحساب قائمًا |
| الحضور والانصراف وموقعهما | تطبيق الموظف | Supabase | كما سبق | ما دام حساب المؤسسة قائمًا |
| نقاط الموقع أثناء الوردية | تطبيق الموظف | Supabase | كما سبق | 30 يومًا أو أقل بإعداد المالك |
| صور الحضور | كاميرا الموظف | تخزين Supabase خاص | كما سبق، وكل فتح يُسجَّل | 90 يومًا أو أقل بإعداد المالك |
| مستندات الإجازة | الموظف | تخزين Supabase خاص | الموظف ومن يراجع إجازته | ما دام السجل قائمًا |
| رمز إشعارات الجهاز ونص الإشعار | التطبيق والخادم | Google Firebase Cloud Messaging | Google لتوصيل الإشعار | يُحذف الرمز عند الخروج |
| البريد (الدعوات، الإجازات، التنبيهات) | الخادم | Zoho Mail | المرسل إليه | حسب صندوق البريد |
| ملفات نسخة الويب | prosm.net | Cloudflare / GitHub Pages | عام (لا بيانات شخصية) | غير منطبق |

**خدمات يتصل بها جهاز المستخدم مباشرة:** OpenStreetMap (الخريطة)، BigDataCloud (اسم المدينة)، Open-Meteo (الطقس)، Radio Browser (الراديو)، خرائط Google (عند الضغط فقط).

**النقل خارج مصر:** بيانات التطبيق في الاتحاد الأوروبي. الموافقة الصريحة تُسجَّل في `data_consents`.

**أدوات حقوق صاحب البيانات:** التصدير `export_prosm_time_employee_data`، والحذف من التطبيق `delete-my-account`، وكلاهما يُسجَّل في `audit_logs` (ذلك هو سجل الطلبات وتواريخها).
